* Scinoj Light

** The story

- We had 3 days to put together a customer demo
- Highly collaborative loop
  - Data
  - Frontend
  - Backend
- Idea was to use Instantdb to collaborate on data
  - Like Google Sheets, but with
    - easier auth
    - schemas
    - a better API

** Quick experiments
- InstantDB quick test (Javascript). Successful.
- Squint. Promising, still in development.
- Decided on Shipclojure

** Stack

Our demo stack
- Noj: to prototype data models and charts
- malli: create synthetic data
- shipclojure: application stack
- instantdb: database
- charting libaries
  - Echarts -> Highcharts -> Recharts

** Workflow
- Figuring out how to minimize blockers
  - e.g. Adham was figuring out how to populate the instantdb tables while Ovi
    was working on visualizing them with a provided shape
  - we agreed on how things should look-like (spec) which enabled front and back
    to work async

** Workflow, continued
- Create charts in Clay
- Screenshot them and put them in draw.io
- Send dashboard prototype for review
- Once approved, integrate to static Recharts
- Wire up with instantdb

** Charting libraries
- Echarts didn't work
- Highcharts worked, but was hard to integrate with React components
- Recharts worked as it was the /easiest/ to move from JS to CLJS

** Takeaways
- The project was a success!
- Demo was actually fairly production ready

** Thoughts on improving this workflow
- Tablecloth for ClojureScript, what is required to get there?
- If that's not possible, how to /bridge/ the two to make it as seamless as
  possible to develop data in .clj and have it read by a .cljs ns?
